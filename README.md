# 3ds Max 材质工具箱（Material Toolkit）

一个**超轻量**的 3ds Max 脚本（MaxScript），把场景里的 V-Ray 材质批量替换成普通材质（Standard / Physical），支持**全场景统一转换**、**转换前自动备份可一键恢复**、**程序贴图烘焙**（解决 FBX 导出兼容），并把所有材质的「构成」导出成对 AI 友好的 Markdown 文档。

没有编译、没有外部依赖、不用装插件管理器——复制粘贴就能跑，稳定性优先。

---

## ✨ 功能特性

### 面板一：材质替换（V-Ray → Standard / Physical）
- **一键替换 V-Ray 材质**：`VRayMtl`、`VRayLightMtl`、`VRayMtlWrapper`、`VRayBlendMtl`、`VRay2SidedMtl`、`VRayOverrideMtl`、`VRayFastSSS2` 及其它所有 `VRay*` 材质，统一转成 Standard 或 Physical。
- **统一转换所有材质**：勾选后 Standard ↔ Physical 双向互转，一键把场景所有材质统一为目标类型。
- **数值参数迁移**：金属度 / 粗糙度 / IOR / 反射色 / 折射 / 自发光等（选 Physical 目标时最完整）。
- **可逆转换**：转换前自动备份原材质为 `.mat`，不满意可「从备份恢复原材质」一键还原。
- **可撤销**：替换操作包了 `undo`，出错随时 `Ctrl+Z`。

### 面板二：程序贴图烘焙（FBX 兼容）
- 用官方 `renderMap` API 把程序贴图（falloff / VRayColor / Color_Correction 等）**烘焙成位图**并可选替换原槽位——解决 FBX 导出后其他软件不识别程序贴图的问题。
- 分辨率 512 / 1024 / 2048 可选。

### 面板三：导出材质构成 MD
- 把场景中每个材质的类型、使用对象、颜色、数值参数、贴图、子材质关系，导出成结构化 Markdown。
- **自带 AI 提示词**：导出 MD 开头内嵌「MD → HTML 报告」转换提示词（HTML 注释），AI 读到就能渲染；面板有「复制 AI 提示词」按钮。

---

## 📋 环境要求

- **3ds Max**（任意较新版本；Physical 材质目标 + 备份恢复需要 3ds Max 2017+）
- 场景里**原本有 V-Ray 材质**即可（本工具不要求本机安装 V-Ray 也能跑替换）

## 🚀 安装与使用

### 1. 安装（两种方式任选）

- **方式 A**：把 `vray_material_replacer.ms` 直接**拖进 3ds Max 视口**，自动运行并弹出工具箱窗口。
- **方式 B**：菜单 `MAXScript → 新建脚本`，打开该文件，按 `Ctrl+E` 运行。
- **方式 C（开机自启）**：复制到 `C:\Users\<用户名>\AppData\Local\Autodesk\3dsMax\<版本> - 64bit\CHS\scripts\Startup\`，重启 3ds Max 自动弹出。

### 2. 面板一：材质替换

1. **目标材质类型**：选 `Standard (标准材质)` 或 `Physical (物理材质)`。
2. （可选）勾选 **统一转换所有材质**——把 Standard/Physical 也一起转到目标类型。
3. 勾选 **保留漫反射/凹凸/透明贴图**（默认开）、**把 VRayBitmap / VRayHDRI 转为 Bitmap**（可选）。
4. 点 **「开始替换 V-Ray 材质」**，底部日志显示替换数量与备份信息。
5. 不满意 → 点 **「从备份恢复原材质」** 一键还原。

> 💡 转换前请**保存场景**；勾选「转换前自动备份」后恢复才有保障（默认勾选）。

### 3. 面板二：程序贴图烘焙

1. 设置**输出目录**（默认场景同目录 `_baked_maps`）。
2. 选**分辨率**，勾选 **烘焙后替换原槽位**（默认开）。
3. 点 **「烘焙程序贴图」** → 完成后 FBX 导出时程序贴图即被位图替代，其他软件可正常显示。

### 4. 面板三：导出材质构成 MD

1. 设置**输出路径**（默认场景同目录 `材质构成报告.md`）。
2. 三个勾选项按需选择：**使用对象** / **贴图** / **数值·颜色参数**（默认全开）。
3. 点 **「导出材质构成 MD」** → 自动生成文件并打开所在文件夹。
4. 需要转 HTML 时，点 **「复制 AI 提示词」** 连同导出的 MD 一起发给 ChatGPT / Claude。

> 想先看结构？`examples/材质构成报告_示例.md` 是假数据示例，不用开 Max 就能试 AI → HTML。

## ⚠️ 已知限制

- **V-Ray 专属参数会被丢弃**：反射细分 / 折射细分 / Fresnel / SSS 在普通材质没有对应项，按「越简单越稳定」原则丢弃。
- **Standard 目标没有金属度**：`metalness` 是 3ds Max 材质系统限制，要保留金属度必须选 **Physical** 目标。
- **替换不可逆（除非备份）**：没勾「自动备份」或改名后，无法用备份恢复；也有 `Ctrl+Z` 可回退本次操作。
- **程序贴图**（VRayDirt / VRayColor 等）在标准/物理渲染下可能显示异常——用面板二烘焙成位图解决。
